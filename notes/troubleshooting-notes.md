# Lab 141 – Troubleshooting Notes

## 1. Microsoft Defender Reported Inactive Protection Features

### Observation

The following Defender properties were reported:

```text
AntivirusEnabled             : True
RealTimeProtectionEnabled    : False
BehaviorMonitorEnabled       : False
```

### Investigation

Further inspection identified:

```text
AMRunningMode : SxS Passive Mode
```

McAfee components were also registered with Windows Security Center, and selected McAfee services were running.

### Interpretation

Defender's passive mode is consistent with another antivirus product being registered on the endpoint.

The initial status output should not automatically be classified as attacker-driven security-control tampering.

The available registration and service information does not independently confirm the health of McAfee's antivirus engine.

### Resolution

No configuration changes were made. The observed protection state was documented as investigation context.

## 2. No Volume Shadow Copies Found

### Observation

Command:

```powershell
vssadmin.exe list shadows
```

Result:

```text
No items found that satisfy the query.
```

### Interpretation

No shadow copies were available to list at the time of inspection.

This result does not identify whether shadow copies were never created, expired, removed through routine administration, or deleted maliciously.

### Resolution

No shadow-copy creation or deletion operation was performed.

It does not establish whether backup schedules exist or whether usable backup data is available.

## 4. Wazuh VSS Idle-Timeout Alert

### Observation

Wazuh rule ID `60702` reported:

```text
The VSS service is shutting down due to idle timeout.
```

The provider was `VSS`, and the event severity was informational.

### Interpretation

A VSS service shutting down because it is idle is different from a command deleting shadow copies.

The alert does not establish malicious activity or backup destruction.

### Resolution

The event was retained as contextual telemetry and was not classified as a ransomware indicator.

## 5. Elevated Sysmon Event ID 11 Counts

### Observation

The 24-hour Event ID 11 baseline contained several minutes with significantly higher file-creation counts than the typical observed baseline.

### Investigation Considerations

A high file-event count can be generated by legitimate application activity, updates, installers, browsers, and background operations.

To investigate an elevated period, correlate:

- `Image` – process responsible for creating the file.
- `TargetFilename` – affected file path.
- `User` – security context.
- Timestamp – whether activity was clustered.
- Event ID 1 – process execution around the same time.

### Interpretation

The spikes are investigation leads, not confirmed mass encryption.

### Resolution

No files were deleted or modified as part of this investigation. The elevated periods were documented for further correlation.

## 7. No Event-Log Clearing Matches

### Observation

No matching Security Event ID `1102` or System Event ID `104` records were found in the queried 30-day history.

### Interpretation

The selected event IDs were not found in the available queried history.

This does not prove that event logs have never been cleared. Retention, collection configuration, and event availability must be considered.

### Resolution

No logs were cleared, and no retention settings were modified.

## 8. Investigation Precautions

- Do not delete shadow copies to simulate ransomware behavior.
- Do not delete backup catalogs.
- Do not modify boot recovery settings.
- Do not disable Defender or other security products.
- Do not clear Windows event logs.
- Do not classify a VSS idle-timeout event as shadow-copy deletion.
- Do not classify file-creation spikes as encryption without supporting evidence.
- Preserve timestamps, process information, and original event records.

## Final Assessment

The investigation did not require destructive remediation or system configuration changes.

The observed conditions were documented as system state, available telemetry, or unresolved investigation leads. No confirmed ransomware activity was established from the available evidence.
